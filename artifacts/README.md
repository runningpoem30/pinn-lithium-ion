# Generated artifacts

This directory contains reproducible audit, training, evaluation, and presentation outputs.

`data_audit.json` is generated by the Step 1 dataset-audit command and is intentionally
kept as a machine-readable record of the processed dataset validation.

Step 2 adds:

- `data_scalers.npz`: non-pickled feature, cycle, and PCL scaler statistics fitted
  exclusively from the official training batteries.
- `data_pipeline_summary.json`: split membership, record counts, and scaler values.

`deephpm/smoke/` contains the bounded Step 4 CPU smoke-test checkpoint,
resolved configuration, scaler copy, per-epoch loss history, and training summary.
It is a software verification run, not an experimental result.

`deephpm/physics_weight_tuning/` contains the Step 5 single-seed validation
sweep, including one reproducible run directory per physics weight and compact
JSON, CSV, and Markdown comparison reports. These are hyperparameter-selection
results, not final test results.

`deephpm/final/` contains the Step 6 final DeepHPM SoH experiment at the frozen
physics weight of `0.001`. Each seed directory contains the validation-selected
checkpoint, training-only scalers, resolved configuration, loss history,
training summary, held-out test metrics, and cycle-level predictions with
physics residuals and battery IDs. The root JSON, CSV, and Markdown reports
summarize all three seeds using the mean and sample standard deviation; no seed
is selected using test performance.

`deephpm/analysis/` contains the Step 7 read-only analysis of those frozen
predictions. It includes aligned three-seed ensemble predictions, aggregate and
per-battery metrics, and eight presentation figures in 300-DPI PNG, SVG, and
PDF formats. Generate it with `python -m src.analyze_final`; this command does
not load a checkpoint or retrain a model.

`protocol/` contains the Step 8 frozen SoH comparison contract and canonical
test keys/targets shared by DataDrivenNN, VerhulstPINN, and DeepHPMNN. The
protocol fixes splits, features, seeds, training-only scaler identity,
validation-only checkpoint selection, metrics, prediction columns, and artifact
paths. Generate and validate it with `python -m src.protocol`; it performs no
training and does not alter completed model artifacts.

`data_driven/final/` contains the Step 9 three-seed DataDrivenNN SoH baseline.
Each run uses the same surrogate architecture and training protocol as DeepHPM
but optimizes normalized PCL data loss only. Seed directories contain the
checkpoint, frozen scalers, resolved configuration, history, training summary,
test metrics, and protocol-aligned cycle-level predictions. Root reports contain
per-seed results and mean/sample-standard-deviation aggregates.

`data_driven/analysis/` contains the read-only analysis of the frozen Step 9
predictions. It includes aligned three-seed ensemble predictions, aggregate and
per-battery metrics, and six presentation figures in 300-DPI PNG, SVG, and PDF
formats. Generate it with `python -m src.analyze_baseline`; the command reads
saved predictions and histories only, and neither loads a checkpoint nor
retrains the baseline.
